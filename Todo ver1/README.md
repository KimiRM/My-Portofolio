# 📋 Todo Manager

> ### Organize. Plan. Achieve.
>
> A cozy, colorful task & event management app built with **Vanilla JavaScript**, **HTML**, and **CSS**. Stay organized with a clean interface, smart filters, and a visual calendar.

---

## ✨ Features

### 📝 Tasks & Events

- Create and manage tasks with start/end times
- Add events with date and duration
- Track progress using a slider (tasks) or toggle (events)
- Set priority levels:
  - 🟢 Low
  - 🟡 Medium
  - 🟠 High
  - 🔴 Urgent
- Categorize items:
  - 👤 Personal
  - 💼 Work
  - 📚 Educational

---

### 🔍 Smart Management

- 🔎 Search tasks by title or description
- 🎯 Multi-filter by:
  - Date range
  - Priority
  - Category
  - Type
  - Progress
- 🗑️ Delete multiple items at once
- ✏️ Inline editing with double-click
- ⚡ Fast and intuitive workflow

---

### 📅 Visual Calendar

- Monthly calendar view
- Event indicators on each day
- Click any date to filter activities
- Day preview showing scheduled tasks and events

---

### 🎨 Beautiful UI

- 🎨 Warm and modern color palette
- ✨ Smooth animations & transitions
- 📱 Responsive layout
- 📊 Circular progress visualization

---

## 🛠️ Technologies

| Technology | Purpose |
|------------|---------|
| HTML5 | Semantic structure |
| CSS3 | Styling, Flexbox, Animations |
| Vanilla JavaScript | Application logic & DOM manipulation |
| Moment.js | Date & time handling |
| Font Awesome & Flaticon | Icons |
| Google Fonts (DynaPuff & Quicksand) | Typography |


---

## 💡 Usage

| Action | How |
|--------|-----|
| ➕ Add Item | Click the **+** button in the right menu |
| ✏️ Edit | Double-click any row |
| 🔎 Search | Click the magnifying glass |
| 🎛️ Filter | Click the slider icon |
| 🗑️ Delete | Select checkbox(es) → Click the trash icon |
| 📅 View by Date | Click any date on the calendar |
